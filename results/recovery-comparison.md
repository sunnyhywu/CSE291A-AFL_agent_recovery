## Notes

* † Restart success is Phase 1's executed live restart (18/18 seed-42 games won).
* "Unauthorized actions executed" counts actions taken in the world over the whole process. A recovery that starts at episode end cannot prevent the faulty run's actions; it only restores the simulated world afterwards (reset). Recovered runs themselves took none.
* Selective recovery was run only with detection at episode end. Detecting the fault at its step would leave nothing to reuse: rolling back would cost about one clean episode, against a restart's pre-fault work plus one clean episode.
* Live recovery made every recomputed call through the API in a fresh cache namespace per recovery; 75 of 778 recoveries hit API timeouts and were rerun. Always verify and the fault runs are Phase 1's cached runs.
* Audit recomputation (checking reused outputs) is not counted: it is an evaluation check, not part of recovery.
